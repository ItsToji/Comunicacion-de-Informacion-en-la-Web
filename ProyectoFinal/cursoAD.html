Análisis de Datos

Área de Formación: Sistemas de Información
Nivel académico: Técnico Medio
Requisito Académico: Bachillerato en Educación Media
Modalidad: Presencial / Virtual
Duración: 5 bimestres / 10 meses
Costo: ₡1 200 000 + 2% IVA

Este programa forma especialistas en la extracción de valor y conocimiento a partir de grandes conjuntos de datos. El estudiante dominará el uso de herramientas de programación esenciales como Python, pandas y NumPy, cubriendo el ciclo completo del análisis: desde la limpieza y transformación de datos (SQL), el análisis exploratorio (EDA) y la Minería de Datos, hasta la aplicación de modelos de Machine Learning y la visualización estadística para la toma de decisiones informada.

Capacitar al estudiante para aplicar técnicas avanzadas de análisis exploratorio, modelado estadístico y Machine Learning, utilizando lenguajes de programación (Python y R) y herramientas de query (SQL) para transformar datos brutos en información estratégica para el negocio.

Dirigido a profesionales con una fuerte afinidad numérica y habilidades lógicas. Se requiere interés en la estadística y la programación, y capacidad para manejar grandes volúmenes de datos. Es ideal para aquellos que buscan aplicar la tecnología a la toma de decisiones en el ámbito de negocios o ciencia.

El egresado será un Analista de Datos o Científico de Datos Junior capaz de programar en Python y R para manipular datos. Podrá realizar consultas SQL complejas, aplicar técnicas de Machine Learning para predicciones, y comunicar hallazgos de manera efectiva a través de visualizaciones y análisis estadísticos en entornos de Business Analytics.

1er Bimestre
- Business Analytics 1
- Fundamentos de Python
2do Bimestre
- Python para el Análisis de Datos
- Introducción a R y Analítica de Datos
3er Bimestre
- Recolección y Preprocesamiento. de Datos (SQL Querying)
- Analisis Exploratorio de Datos (EDA)
4to Bimestre
- Minería de Datos
- Machine Learning 1
5to Bimestre
- Machine Learning con Python Avanzado
- Visualización y Análisis Estadístico 1
