Desarrollo y Diseño Web

Área de Formación: Ingeniería del Software
Nivel académico: Técnico Medio
Requisito Académico: Bachillerato en Educación Media
Modalidad: Presencial / Virtual
Duración: 5 cuatrimestres / 1 año y 8 meses
Costo: ₡2 400 000 + 2% IVA

Este curso integral proporciona las habilidades esenciales para la creación de soluciones digitales funcionales y atractivas. Los estudiantes dominarán el ciclo de vida completo de un proyecto web, abarcando desde el Diseño de Experiencia de Usuario (UX/UI) y la maquetación visual (Front-End con HTML, CSS y JavaScript), hasta la programación de la lógica de negocio y la gestión de bases de datos (Back-End). Al finalizar, el egresado estará capacitado para construir sitios y aplicaciones responsive, robustas y optimizadas para el entorno digital actual.

Capacitar al estudiante para dominar el ciclo de vida completo del desarrollo web, logrando diseñar, implementar y desplegar sitios y aplicaciones web funcionales (Front-End) y robustas (Back-End), utilizando las tecnologías y metodologías estándar de la industria (HTML5, CSS3, JavaScript, bases de datos y frameworks modernos).

El curso está diseñado para individuos con una fuerte motivación por la creación y la tecnología. Los aspirantes deben poseer habilidades lógicas y de resolución de problemas, y demostrar comodidad en el manejo de herramientas informáticas y la navegación en internet. Se requiere una actitud proactiva y disciplina para el estudio constante, dada la evolución acelerada del ecosistema web. Es valorable, aunque no indispensable, contar con nociones básicas de diseño o familiaridad previa con conceptos de programación.

El egresado será un desarrollador con capacidad para construir soluciones digitales completas. Podrá diseñar y maquetar interfaces web visualmente atractivas y adaptables (responsive), implementando la lógica interactiva (Front-End). Además, dominará la programación del lado del servidor (Back-End) para gestionar bases de datos y asegurar la funcionalidad del sitio. Estará preparado para utilizar herramientas de colaboración como Git y desplegar proyectos de manera profesional en el entorno digital.
