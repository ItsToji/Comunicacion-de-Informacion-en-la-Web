Administración de Bases de Datos

Área de Formación: Ingeniería del Software
Nivel académico: Técnico Medio
Requisito Académico: Bachillerato en Educación Media
Modalidad: Presencial / Virtual
Duración: 3 cuatrimestres / 1 año
Costo: ₡700 000 + 2% IVA

Este curso se centra en las técnicas fundamentales para el diseño, implementación y gestión eficiente de bases de datos relacionales. El estudiante dominará el modelado lógico de datos (entidad-relación), la optimización mediante normalización e índices, la escritura de consultas SQL avanzadas, y la administración práctica del sistema, incluyendo la gestión de respaldos (backups) en plataformas como MySQL y PostgreSQL.

Capacitar al estudiante para diseñar, implementar, consultar y mantener bases de datos relacionales robustas y optimizadas, dominando el lenguaje SQL y las mejores prácticas de administración de sistemas gestores como MySQL y PostgreSQL.

Dirigido a personas con interés en la organización y manipulación de grandes volúmenes de datos. Se requiere capacidad lógica para el modelado estructurado de información y un manejo cómodo de la computadora. Es valorable, aunque no indispensable, contar con conocimientos básicos de algún lenguaje de programación o experiencia previa en sistemas informáticos.

El egresado será un administrador de bases de datos con la capacidad de diseñar modelos de datos normalizados, escribir consultas SQL complejas y optimizar el rendimiento de la base de datos mediante índices. Podrá implementar y gestionar tareas de mantenimiento crítico, como la seguridad y los respaldos, en entornos de producción utilizando MySQL y PostgreSQL.
