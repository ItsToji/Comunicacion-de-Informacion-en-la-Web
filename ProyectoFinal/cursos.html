Cursos

Ofrecemos cursos prácticos y certificados en programación, diseño web, bases de datos, ofimática, disponibles en forma presencial y en línea para impulsar tu formación profesional.

Desarrollo y Diseño Web

Aprende a crear sitios web responsivos con HTML5, CSS3, Bootstrap y JavaScript. Cubre maquetación, diseño adaptativo, accesibilidad y un proyecto práctico para tu portafolio.

Soporte Técnico

Aprende a diagnosticar y resolver problemas de hardware y software, realizar mantenimiento preventivo, gestionar redes locales y aplicar medidas básicas de seguridad informática. Incluye prácticas y casos reales.

Más Información
Administración de Bases de Datos

Aprende a diseñar, implementar y optimizar bases de datos relacionales. Cubre modelado entidad‑relación, SQL, normalización, índices, backups y administración práctica con MySQL y PostgreSQL.

Tecnologías de la Información

Aprende fundamentos de hardware, sistemas operativos, virtualización, seguridad informática y administración de servicios en la nube. Incluye prácticas, gestión de proyectos TI y herramientas para soporte.

Ofimática

Aprende a utilizar herramientas de oficina como procesadores de texto, hojas de cálculo y presentaciones. Incluye prácticas para mejorar la productividad y organización.

Redes - CCNA

Domina el diseño, configuración y resolución de problemas en redes empresariales, TCP/IP, servicios de red y seguridad. Incluye prácticas hands-on con simuladores, laboratorios reales y preparación para la certificación CCNA.

Amazon Web Services

Aprende a utilizar los servicios en la nube de Amazon Web Services (AWS) para implementar y gestionar infraestructuras escalables y seguras. Incluye prácticas con EC2, S3, Lambda y más.

Aprende a diseñar interfaces y piezas visuales para la web: identidad visual, tipografía, color y composición. Trabaja con Figma, Adobe XD, Photoshop e Illustrator; crea prototipos responsivos, optimiza imágenes para la web y aplica buenas prácticas de UX y accesibilidad.

Análisis de Datos

Aprende a analizar y visualizar datos utilizando herramientas como Python, pandas y NumPy. Incluye limpieza y transformación de datos, análisis estadístico y creación de visualizaciones.
